AXIOM Quant Research Portfolio

A research project focused on equity signal design, backtest integrity, and model risk controls. The work is presented as a quant research case study: define a signal hypothesis, validate it with leakage-aware methods, compare it against baselines, and report the result honestly.

Research Question

Can daily price and volume features produce an economically meaningful out-of-sample equity signal after execution costs and multiple-testing adjustment?

Validation Controls

The current harness uses train-fold-only scaling, purged and embargoed walk-forward validation, next-day execution, explicit cost plus slippage, buy-hold and random baselines, and a deflated Sharpe adjustment using a lower-bound count of prior model trials.
